# Nori

> Nori (Nori Robotics) is a Y Combinator (Summer 2026) hard-tech company building affordable bimanual humanoid home robots — the NORI L2, a sub-$1,300 wheeled robot with dual Z-axis lift arms that autonomously handles household chores. Nori also ships @nori/sdk, an Apache-2.0 robot-local teleoperation SDK that connects to a robot over WebRTC to stream video/telemetry and drive it from the browser in ~20 lines. This is an API Evangelist enrichment profile generated from the public developer surface.

## Notes
- The SDK is distributed as a tarball to a small set of collaborating developers; it is NOT on public npm.
- The SDK speaks WebRTC to a local robot daemon (nori-protocol v1, port 7777) — there is no hosted REST API base URL.
- No OpenAPI, AsyncAPI, MCP server, OAuth scopes, /.well-known documents, status page, or changelog were found at enrichment time.
